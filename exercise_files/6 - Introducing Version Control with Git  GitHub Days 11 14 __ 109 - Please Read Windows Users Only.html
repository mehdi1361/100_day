Please read if you're working on a Windows computer

In the next lecture, we'll learn about the Personal Access Token, a key which gives us access to our GitHub account via Git.

In case you want to delete this token from your machine (e.g. to add a new one), please run the following command in the integrated command prompt in VS Code instead of the command shown for Mac users at 7:40 in the next lecture: 


git credential reject => ENTER
host=github.com => ENTER
protocol=https => ENTER
