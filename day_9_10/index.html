HTML & CSS Basics Summary

HTML Summary

HTML is the standard markup language for creating web pages. It provides the structure and content of a webpage, allowing developers to define headings, paragraphs, links, images, and other elements.

  • HTML stands for HyperText Markup Language.
  • HTML is used to create the structure of web pages.
  • HTML elements are represented by tags, such as <h1>, <p>, <a>, etc.
  • HTML documents have a hierarchical structure with a root element (<html>), head (<head>), and body (<body>).
  • Attributes provide additional information about HTML elements, such as class, id, href, src, etc.

CSS Summary

CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation and layout of HTML elements. It allows developers to control the visual appearance of web pages, including colors, fonts, spacing, and positioning.

  • CSS stands for Cascading Style Sheets.
  • CSS is used to style and format the appearance of web pages.
  • CSS rules consist of selectors and declarations, where selectors target HTML elements and declarations define their styles.
  • CSS can be applied inline, internally within a <style> tag, or externally through a separate .css file.
  • CSS supports various properties for styling, such as color , font-size, margin, padding, display, etc.
